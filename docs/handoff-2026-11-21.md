## Environment gotchas

- Dev server: `.runtime\run-local-dev.cmd` / `run-local-dev-debug.cmd` → game `http://localhost:5173/?game=tavern`, API 4000.
- Vite on Windows sometimes serves a stale/truncated file after an edit: `touch` the file.
- Some sandboxes cannot delete files in the repo, so git leaves `.lock` / `tmp_obj` files; move stale locks to `.git/stale-*`. `.runtime/_to_delete/` holds leftovers safe to delete.
- Browser automation in a hidden tab pauses requestAnimationFrame/WAAPI: use `?rafTimer` on the dev server.
- Unit tests: `npm test`. Playwright may fail in sandboxes (EPERM / webServer); run `npm run test:browser` on the Windows machine.
